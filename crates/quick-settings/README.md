# Mechanix Quick Settings

The launcher's quick settings panel, built with [`mecha-wayland`](https://github.com/mecha-org). It is a library crate; the launcher shows it as the right half of the top-edge panel through `nav`.

It provides a brightness slider, Wi-Fi, Bluetooth and battery tiles, and a power-off/restart overlay, backed by the shared [`services`](../services) crate.
